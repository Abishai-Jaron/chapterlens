ChapterLens

A free browser-based readability tool for authors.

What it does

ChapterLens lets an author paste a chapter and instantly see:

- Readability score
- Approximate grade level
- Word and sentence count
- Average words per sentence
- Five hardest sentences
- Hardest sentences highlighted directly in the chapter

How it works

The tool runs entirely in the browser using JavaScript. The pasted text is analyzed locally and is not uploaded to a server.

Built with

- HTML
- CSS
- JavaScript
- ChatGPT for ideation, coding, and debugging

Purpose

The goal is to give authors a quick way to identify sections that may require easier wording or editing.

Disclaimer

Readability scores are estimates and should not be treated as a measure of writing quality.
